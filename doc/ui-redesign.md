# AIVideo Studio UI 重設計線框

> 本文件取代「左欄工作流大按鈕 + 頂部四步 Stepper 並存」的舊架構。  
> 原則：左欄只切頁、頂列只放狀態與一顆主按鈕、右欄按需開啟、每頁只有一個主角。

---

## 0. 設計決策（已鎖定）

| 項目 | 決定 |
|---|---|
| 導航 | 只留左側窄欄。不使用頂部 Stepper / 第二套頁籤 |
| 頂列 | 專案、完成度、1 顆主 CTA、次要進 `⋯` |
| 右欄 | 僅「選取分鏡」或「編輯素材」時開啟 |
| 主按鈕 | 跟專案狀態走，不跟頁名走 |
| 視覺 | 近黑電影風；琥珀只給「左欄現在頁」與「唯一實心按鈕」 |
| 舊 Sidebar | 移除系統長狀態文、四顆同等工作流鍵、專案摘要膠囊堆疊 |

主按鈕狀態對照：

| 專案狀態 | 頂列主按鈕 |
|---|---|
| 尚無可用腳本 | 生成腳本 |
| 有分鏡、缺圖 | 生成未完成畫面 |
| 圖齊、缺聲 | 生成配音 |
| 圖聲齊、無成片 | 合成 1080p |
| 已有成片 | 預覽成片 |
| 批次進行中 | 進度條 + 暫停 |

### 1.1 左欄規格

- 展開 220px / 收合 64px（只留圖示）
- 項目：`總覽` `腳本` `分鏡` `成片` `素材` `設定`
- 現在頁：琥珀色字 + 左側 3px 色條
- 只負責切頁
- 不放：Gemini/Comfy 長文、工作流大按鈕、批次生成、分鏡數膠囊

### 1.2 頂列規格

- 左：專案下拉（可含重新整理於下拉尾端）
- 中：完成度一句 `圖 4/6 · 聲 6/6 · 未合成`
- 右：1 顆實心主按鈕 + `⋯`
- `⋯` 內容示例：匯出 MP4 / SRT / ASS / HTML、強制全覆蓋生成、刪除專案入口
- 系統連線改成兩個極小圓點，hover 才顯示詳情
- 禁止再放「發想 → 分鏡 → 成片 → 素材」

### 1.3 右欄規格

- 預設關閉，主畫布吃滿
- 開啟時機：分鏡卡片被選取、素材卡片被編輯
- 可關閉（X）；關閉後選取態可保留，但不佔版面

### 1.4 視覺 token

| Token | 值 |
|---|---|
| 背景 | `#0B0B0D` |
| 卡片 | `#16161A` |
| 線 | `#2A2A30` |
| 強調 | `#E8B86D` |
| 正文 | `#E8E8EA` |
| 輔助 | `#8A8A93` |
| 圓角 | 8–12px |
| 頁邊 | 24px |
| 欄距 | 16–20px |
| 主畫布最大寬 | 1440px，更寬留黑邊 |

字級：頂列/左欄 13、頁內標題 18–20、本文 14、輔助 12。

### 行為

- 風格畫廊不進第一屏；點「更換」才開 overlay / modal（5 欄可保留在 modal 內）
- 聯網檢索、字數滑桿放進編輯器上方的「進階」展開
- 「載入現有專案腳本」放編輯器選單，不與主按鈕並列
- 有腳本之後才展開「建立專案」
- Job 名稱可用主題自動 slug，允許事後改

### 禁止

- 15 張風格牆直接攤在主題下方
- 「🚀 呼叫 Gemini 聯網搜集資料並生成腳本口白」這類長按鈕當主視覺

## 4. 頁面：分鏡（主戰場 / 視覺錨點）

左欄高亮 `分鏡` · 選取後右欄開啟 · 主按鈕依狀態（預設 `生成未完成畫面`）

```
│  出圖    配音    考據    合成    設定               │

┌────────────┬────────────┬────────────┐   ┌ 右欄 ─────────┐
│ 01     ✅  │ 02     ⚠圖 │ 03     ✅  │   │ 第 03 / 06 幕  │
│  [16:9]    │  [16:9]    │  [16:9]    │   │ ◀  上一  下一 ▶│
│  深空哈勃  │  鏡頭推進  │  儀器特寫  │   │                │
│  00:06     │  00:07     │  00:08     │   │ [16:9 預覽]    │
└────────────┴────────────┴────────────┘   │ 重抽 換圖 重錄 │
┌────────────┬────────────┬────────────┐   │                │
│ 04     ✅  │ 05     ⚠聲 │ 06    PiP  │   │ 旁白           │
│  [16:9]    │  [16:9]    │  [16:9]    │   │ Prompt         │
│  …         │  …         │  …         │   │ PiP 位置/比例  │
└────────────┴────────────┴────────────┘   │ 搜尋真實照片   │
                                           └────────────────┘
```

### 卡片

- 內容：縮圖、幕次、短標題、秒數、一顆狀態徽章
- 整卡可點 = 選取並開右欄
- hover 才顯示更多，不常駐兩行旁白與大按鈕

### 右欄精修順序（固定）

1. 預覽  
2. 重抽 / 換圖 / 重錄（圖示）  
3. 旁白  
4. 英文 Prompt + 儲存  
5. PiP  
6. 搜尋真實照片（進階展開）

### 設定（指揮列「設定」開 modal / 次級抽屜，不要再佔主畫布頂部）

- 定裝圖 / 視覺錨點  
- 發音人與畫風  
- 完整劇本唯讀  
- 刪除專案（二次確認）

第一次進入尚無定裝圖時，可用一次性橫幅：「先定主角長相，後面比較穩」，不要每次都把定裝面板撐開。

### 進行中

- 進度併入頂列主按鈕位置
- 直接刷新對應卡片，不另開同步預覽窗
- 暫停 / 中止放進度旁

### 禁止

- 頂部大 Drawer + 一排長按鈕 + Runner + 網格 + Inspector 全部平鋪
- 清單模式與網格同等強調（清單可進指揮列切換）

### 三種資產同一套肌肉記憶

| Tab | 卡片預覽 | 右欄必填 | 右欄進階（預設藏） |
|---|---|---|---|
| 口吻 | 首段規則摘要 | 名稱、Markdown | 刪除 |
| 發音人 | 波形 + 試聽 | 名稱、參考音、逐字稿 | speed / steps / temperature |
| 風格 | 示範圖 | 名稱、描述、正負向詞、示範圖 | — |

新增用短流程，不要在列表下方展開長表單。

## 7. 頁面：設定

左欄高亮 `設定` · 右欄關閉

只放全域、低頻項目：

- 外觀（深色為預設）
- Gemini / ComfyUI 連線詳情
- 預設口吻、預設發音人、預設風格
- 危險區：快取、日誌

專案級刪除仍放在分鏡「設定」，不放這裡以免刪錯對象。

## 8. 跨頁流程（對應舊手冊 Workflows）

### A. 從零到成片

1. 左欄 `腳本` → 填主題、口吻、發音人、選風格  
2. 頂列 `生成腳本` → 編輯器審稿  
3. 展開建立專案 → 自動進 `分鏡`  
4. 若無定裝圖，看一次引導橫幅  
5. 頂列 `生成未完成畫面`（或之後的配音 / 合成）  
6. 左欄 `成片` 看片下載  

### B. 單幕不满意

1. `成片` 時間軸 hover → 跳轉精修  
2. 落地 `分鏡` 且右欄已鎖定該幕  
3. 重抽 / 重錄 / 改 Prompt  
4. 頂列或指揮列 `合成 1080p`  

### C. 換畫風重產

1. 分鏡指揮列 `設定` → 換風格並套用  
2. 視需要重寫全部 Prompt（二次確認）  
3. `⋯` 裡選強制覆蓋後出圖  
4. 合成

## 9. Streamlit 對應（實作備忘）

| 線框區塊 | 建議元件 |
|---|---|
| 左欄 | `st.sidebar` 只留 nav radio/buttons；或自訂 HTML rail |
| 頂列 | 主頁第一列 `st.columns`，主按鈕 `type="primary"` 全頁唯一 |
| 右欄 | `st.expander` 不夠；優先 `st.dialog` 或自訂兩欄 `columns([3,1])`，無選取時 `columns([1])` |
| 風格更換 | `st.dialog` / modal |
| 分鏡網格 | 3 欄 `columns` + 卡片 container |
| 進行中 | 頂列按鈕位置換成 `st.progress` |
| 主題 | 自訂 CSS：壓預設 padding、統一卡片、深色 |

文案一律短標籤：`生成腳本`、`出圖`、`配音`、`合成`、`匯出`。不要中英並陳長按鈕。

## 10. 驗收清單

- [ ] 四頁左欄樣式一致，現在頁只有一條琥珀指示  
- [ ] 頂列沒有四步 Stepper  
- [ ] 任一瞬間只有一顆實心主按鈕  
- [ ] 腳本第一屏沒有風格大海報牆  
- [ ] 分鏡點卡片即開右欄，頁面不因此再往下加倍  
- [ ] 成片以播放器為唯一主角，下載在 `⋯`  
- [ ] 素材列表不露出 steps / temperature  
- [ ] 高風險操作（全覆蓋重產、重寫全部 Prompt、刪專案）有確認

## 11. 刻意不做

- 左欄 + 頂部 Stepper 雙導航  
- 把 Pipeline Runner 做成第二個預覽舞台  
- 用更多 emoji 提升「親和」  
- 為了塞功能把主畫布拆成四個同等區塊  

本線框的完成定義：創作者在任一頁都能回答兩句話——「我在哪一頁」以及「現在該按哪一顆」。
