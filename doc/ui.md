## 1. 系統啟動與環境監控

- **服務網址**：`http://localhost:8501`（或容器內 `0.0.0.0:8501`）
- **VS Code Tasks 快捷控制**：
  - `AIVideo: 🌐 啟動 Streamlit 說書人網頁控制台 (Port 8501)`：自動清理佔用埠號並在 Docker 容器內常駐執行。
  - `AIVideo: 🛑 停止 Streamlit 網頁控制台 (釋放 8501 埠)`：強制關閉釋放資源。
- **終端機手動指令**：
  ```bash
  docker compose run --rm -p 8501:8501 pipeline streamlit run aivideo/webui.py --server.port 8501 --server.address 0.0.0.0
  ```

## 3. 頁面 1：✍️ 劇本發想與創作 (Script Studio)

用於將創作靈感透過 Gemini 聯網搜集資料，套用指定口吻，產出符合語音合成規範的深度說書腳本。

### 3.1 故事參數設定
- **📌 故事主題**：自訂主題（如：「羅曼太空望遠鏡的秘密」、「光刻機霸主艾司摩爾的崛起」）。
- **📏 需求字數規模**：以 100 字為單位精細調整（300 ~ 5000 字）。
- **🌐 Google 即時聯網事實檢索 (Search Grounding)**：勾選後 Gemini 會在背後搜尋真實論文、歷史事件與新聞資料，挖掘數據與名場面。
- **🎭 說書人口吻風格 (Tone)**：選用 `assets/tones/*.md` 預設範本（如硬核科普、商業反轉、懸疑冷硬、溫暖敘事）。
- **🎙️ 選擇發音人 (Voice)**：選用預設配音角色。
- **💡 預估規格即時試算**：滑動字數時自動顯示預估總字數、預估切分分鏡數與成片預估秒數。

### 3.2 視覺風格縮圖畫廊 (Style Gallery)
- **橫幅提示**：顯示當前選定的風格名稱、ID 與風格特色說明。
- **5 欄式縮圖卡片牆**：
  - 完整展示 15 種視覺大師畫風（吉卜力、大友克洋、新海誠、荒木飛呂彥、鳥山明、三浦建太郎、京都動畫、ufotable、TRIGGER、手塚治虫等）。
  - 每張卡片均具備風格預覽圖與選用按鈕，點擊立即選定並帶有發光藍色邊框。

### 3.3 腳本生成與編輯
- **🚀 呼叫 Gemini 聯網搜集資料並生成腳本口白**：啟動雲端聯網生成。
  - **自動遵守的語音規範**：每行一句話、標點嚴格限制只允許逗號「，」、問號「？」與感嘆號「！」（問號感嘆號極度克制）、外語詞彙一律中譯、適度嵌入 OmniVoice 情緒副語言標籤（如 `[surprise-wa]`、`[sigh]`）。
- **📝 口白腳本編輯區**：文字框支援在線即時潤色、修改台詞。
- **📥 載入現有專案腳本**：可一鍵將左側選中專案的 `script.md` 載入編輯區二次創作。

### 3.4 專案打包建立
- **🖼️ 每張圖片搭配句數**：建議 2~3 句換一張圖。
- **📁 新 Job 資料夾名稱**：指定英數 slug（預設為 `YYYYMMDD_new_story`）。
- **✨ 正式建立為新專案 (Create Job)**：
  1. 自動呼叫 AI 提煉全片主體特徵與環境光影錨點 (`visual_anchors`)。
  2. 自動切分分鏡、前置分析考據實體 (PiP)。
  3. 生成全部分鏡之專業英文出圖提示詞。
  4. 寫入 `jobs/<job_id>/` 並**自動跳轉至「🎞️ 分鏡看板」**展開製作。

## 4. 頁面 2：🎞️ 分鏡看板與生成 (Storyboard & Production)

這是整個專案的核心導演工作台，負責所有畫面的生圖、配音、考據配圖、微調與成片合成。

### 4.1 專案導演設定中心 (Project Settings Drawer)
位於分鏡看板頂部的整合抽屜，點擊展開後分為 4 個標籤頁：
1. **🎭 視覺特徵錨點與定裝圖 (Visual Continuity Anchors)**：
   - **主體定裝基準圖 (Hero Shot)**：可點擊「🎲 產生」由 AI 繪製全片視覺基準，或自行上傳參考圖。
   - **多模態圖片參考開關**：勾選後 Gemini 出圖時將直接讀取定裝圖，鎖定角色外貌、服裝與機械細節。
   - **核心特徵錨點 (Prompt)**：可修改主體結構錨點與環境光影基調錨點，並可點擊「🔄 依最新錨點重新產生所有分鏡 Prompt」一鍵同步刷新全片提示詞。
2. **⚙️ 發音人與視覺風格配置**：
   - 線上切換專案發音人。
   - 線上切換畫面視覺風格（支援展開 5 欄縮圖畫廊快速選取）。
   - 點擊「💾 儲存並套用至專案」立即更新 `job.yaml`。
3. **📜 完整劇本台詞 (script.md)**：檢視目前專案逐行台詞與總字數統計。
4. **🗑️ 專案維護與刪除**：勾選確認後可安全刪除當前專案資料夾。

### 4.2 批次生成控制與快捷按鈕組
- **執行選項**：
  - `⚡ 僅生成未完成場景`：增量續跑模式，已產出者自動跳過；取消勾選則強制整部覆蓋重新生成。
  - `🌐 全流程包含自動檢索考據圖 (Auto-PiP)`：一鍵全流程時，自動由 AI 掃描台詞向維基百科/開放圖庫配對真實歷史檔案與論文圖表。
  - `⏸️ 階段完成後自動暫停`：生圖或配音結束後自動暫停，供導演看板審查確認後再繼續。
- **一鍵快捷操作按鈕組**：
  - `🎨 批次出圖 (Images)`：透過 Gemini API 批次生成全部分鏡 16:9 畫面。
  - `🎙️ 批次配音 (Voice Clone)`：透過 ComfyUI OmniVoice 批次合成逐場語音並測量真實秒數。
  - `🌐 自動考據配圖 (Auto-PiP)`：批次檢索真實照片並掛載畫中畫卡片。
  - `🎬 合成 1080p 成片 (Compose)`：調用 FFmpeg 執行 Ken Burns 推鏡、旁白混音與字幕壓製。
  - `🚀 全流程一鍵自動生成 (All-in-One)`：一鍵依序執行上述全部步驟。

### 4.3 背景任務即時控制台 (Pipeline Runner)
當批次任務進行中時，頂部顯示：
- **即時進度條與狀態訊息**（例如：`進行中：Images 正在生成第 3/6 幕`）。
- **控制按鈕**：`⏸️ 暫停執行` ｜ `▶️ 繼續執行` ｜ `⏹️ 中止執行`。
- **動態同步預覽視窗**：邊跑邊動態刷新最新生成的 16:9 畫面、考據圖與音訊試聽播放器。

### 4.4 分鏡看板指標與檢視模式
- **即時指標**：畫面完成度卡片、語音完成度卡片、總旁白累計時長、1080p 成片狀態。
- **過濾顯示選單**：`全部場景` ｜ `僅看待處理 (缺圖或缺音)` ｜ `僅看已就緒 (圖音皆齊)`。
- **雙重視圖模式**：
  1. **🎨 故事板網格 (Storyboard Grid - 推薦)**：
     - 每行 3 個 16:9 縮圖卡片牆。
     - 卡片包含：縮圖、幕次、標題、秒數、狀態徽章（`✅ 就緒`、`⚠️ 缺圖`、`⚠️ 缺音`、`🖼️ PiP`）、兩行旁白摘要。
     - 點擊卡片上的「🎯 精修此幕」按鈕，立即鎖定並在下方展開精修工作台。
  2. **📜 詳細清單 (List View)**：傳統垂直折疊清單展開模式。

### 4.5 🎯 焦點分鏡精修工作台 (Scene Inspector)
點選任一分鏡卡片後，展開專屬精修面板：
- **頂部快速導覽**：`[◀ 上一幕]` ｜ `目前焦點：第 X / Y 幕` ｜ `[下一幕 ▶]`，支援順暢翻閱。
- **左半部（畫面與音訊）**：
  - 16:9 主畫面高解析預覽。
  - 語音播放器（可直接點擊試聽該幕口白）。
  - `🎲 重抽這張圖`：以新隨機 Seed 重新呼叫 Gemini 繪製該幕。
  - `🎙️ 重錄這段聲音`：重新呼叫 ComfyUI 克隆該幕語音。
  - `📁 替換為主畫面`：支援上傳本機圖片或輸入網路圖片 URL 直接替換主畫面。
- **右半部（文案與考據）**：
  - 🗣️ **旁白台詞**：查看該幕具體中文台詞。
  - 🎨 **畫面提示詞 (English Image Prompt)**：文字框支援線上修改英文提示詞，點擊「💾 儲存修改提示詞」即時生效。
  - 🖼️ **畫中畫考據卡片 (PiP Overlay)**：
    - 支援疊加真實歷史照片、文獻圖表（自動帶精緻白邊、外陰影與淡入動畫）。
    - 設定疊加位置（右上角、左上角、右下角、左下角、畫面置中）。
    - 調整卡片寬度比例（20% ~ 60%）。
    - 支援本機上傳圖片、貼上圖片 URL 或一鍵移除。
  - 🔍 **線上搜尋真實照片 (NASA / 維基百科 / 開放圖庫)**：
    - 輸入中英文關鍵詞（如 `Hubble`、`ASML`、`Worker Ant`）。
    - 點擊「🔎 搜尋」展示多圖候選結果。
    - 每張候選圖提供兩個一鍵按鈕：`📌 套用為畫中畫 (PiP)` 或 `🖼️ 替換為 16:9 主畫面`。

## 5. 頁面 3：📺 1080p 成片預覽 (Film Preview & Landmarks)

成片合成後的檢閱與下載中心。

### 5.1 影片播放與匯出
- **成片播放器**：內嵌 HTML5 Video 播放器，完整預覽 1080p 寬銀幕、Ken Burns 運鏡、配音與字幕合流效果。
- **4 大資產下載按鈕**：
  - `📥 下載 1080p 影片 (MP4)`
  - `📥 下載 SRT 字幕檔 (timeline.srt)`
  - `📥 下載 ASS 樣式字幕 (timeline.ass)`
  - `[在新分頁打開 HTML 故事板] (preview.html)`

### 5.2 ⏱️ 成片時間軸與分鏡導航 (Timeline Landmarks)
- 成片下方依序排列各場景的累計時間區間（例如 `00:00 ~ 00:08`、`00:08 ~ 00:15`）。
- 每幕展示：縮圖、幕次、時間範圍、旁白台詞。
- **🎯 跳轉精修此幕按鈕**：在審片時若發現某一幕畫面或語音不理想，點擊此按鈕，系統會**自動切換至「🎞️ 分鏡看板」並直接鎖定該幕焦點**，修改完成後一鍵重新合成即可。

## 6. 頁面 4：🎙️ 素材資產管理中心 (Assets Studio)

全域素材庫的全生命週期管理（增、刪、改、查、試聽）。

### 6.1 🎭 說書人口吻風格 (Tone)
- 檔案路徑：`assets/tones/<ID>.md`。
- **現有口吻檢視與編輯**：線上微調 Markdown 規則與說書人設定，點擊儲存；支援危險刪除。
- **新增自訂口吻**：輸入英文 ID 與 Markdown 範本，新增後立即同步至劇本發想下拉選單。

### 6.2 🎙️ 發音人音色庫 (Voice)
- 檔案路徑：`assets/voices/<ID>/`（包含 `voice.yaml`、`reference.wav`、`reference.txt`）。
- **現有發音人管理**：
  - 試聽參考音訊 `reference.wav`。
  - 微調顯示名稱、模式 (`clone` 聲音克隆 / `design` 語氣設計)、語速 (`speed` 0.5~2.0)、位置溫度 (`position_temperature`)、推論步數 (`steps`)。
  - 編輯參考音逐字稿 `reference.txt`。
  - 支援上傳新的音訊覆蓋替換。
- **新增發音人角色庫**：
  - 上傳 5~15 秒無背景音樂的乾淨人聲音訊。
  - 輸入 100% 精確吻合的中文逐字稿。
  - 建立後即可在所有專案中切換為該發音人。

### 6.3 🎨 畫面視覺風格 (Style)
- 檔案路徑：`assets/styles.yaml` 與 `assets/styles/previews/*.jpg`。
- **現有視覺風格管理**：
  - 檢視示範預覽圖。
  - 線上修改風格顯示名稱、特色描述、正向前綴提示詞 (`prefix`) 與負向過濾詞 (`negative`)。
  - 支援上傳新圖片替換示範預覽圖。
- **新增自訂視覺風格**：
  - 定義風格 ID、名稱、正負向提示詞與示範圖，新增後立即注入至 5 欄風格縮圖畫廊中。

## 7. 常見實戰操作流程 (Workflows)

### 流程 A：從零到成片標準流程（5 分鐘產出）
1. 在左側選單進入「✍️ 劇本發想」。
2. 輸入故事主題、選擇字數規模（如 1500 字）、選定說書人口吻與發音人。
3. 在「視覺風格縮圖畫廊」點擊任一喜愛的畫風卡片（如大友克洋或吉卜力）。
4. 點擊「🚀 呼叫 Gemini 聯網搜集資料並生成腳本口白」。
5. 在文字框審閱台詞後，點擊「✨ 將上方腳本正式建立為新專案」。
6. 系統自動跳轉至「🎞️ 分鏡看板」，點擊「🚀 全流程一鍵自動生成 (All-in-One)」。
7. 生成結束後，在左側切換至「📺 成片預覽」播放並下載 1080p 成片。

### 流程 B：單幕畫面或聲音不滿意微調
1. 在「📺 成片預覽」觀看影片時，在下方「時間軸分鏡導航」找到不滿意的那一幕，點擊「🎯 跳轉精修此幕」。
2. 系統自動跳轉至「🎞️ 分鏡看板」並鎖定該幕。
3. 若是畫面不滿意：點擊「🎲 重抽這張圖」或在右側微調英文 Prompt 後重抽；亦可展開開放圖庫搜尋真實照片套用。
4. 若是聲音不滿意：點擊「🎙️ 重錄這段聲音」。
5. 修改完成後，點擊上方「🎬 合成 1080p 成片 (Compose)」即可（只花 2~3 秒即可重新壓出最新成片）。

### 流程 C：全片更換畫風重產
1. 在「🎞️ 分鏡看板」頂部點開「🛠️ 專案導演設定與視覺一致性中心」。
2. 切換至「⚙️ 發音人與視覺風格配置」，展開畫廊點擊新風格，點擊「💾 儲存並套用至專案」。
3. 切換至「🎭 視覺特徵錨點與定裝圖」，點擊「🔄 依最新錨點重新產生所有分鏡 Prompt」。
