# 4000字深度故事腳本生成指令範本 (Story Generation Prompt Template)

當需要生成長篇（約 4000 字、12～15 分鐘）的 YouTube 深度說書腳本時，採用此標準指令範本。

---

## 標準呼叫指令格式

```text
介紹【主題名稱】
需求 4000 字的中文介紹故事
盡可能地找更多參考資料
使用如下口語化風格：【指定風格代號，例如 tech_business_deepdive】
請以一句一句口白腳本的樣式生成
盡量不要有英文
標點符號只允許"，?!"
```

---

## 規則解析與執行規範

1. **篇幅規模（約 4000 字）**：
   - 故事結構完整，涵蓋 6～8 個核心章節（起承轉合、歷史背景、核心矛盾、技術/商業原理拆解、傳奇衝突、高潮反轉、人文昇華結尾）。
2. **多源資料檢索（Search Grounding）**：
   - 深入挖掘該主題真實歷史、人物生平、名場面對話、技術演進細節與數據，避免空泛流水帳。
3. **風格融合（Tone Alignment）**：
   - 讀取指定的 `assets/tones/{tone_id}.md` 範本（如杜比模式的「賣奶油不賣蛋糕」、商業教科書三部曲、「大家想想看」互動口吻）。
4. **逐行獨立口白（Sentence-by-Sentence）**：
   - **一行一句獨立台詞**。
   - 每行長度適中（12～25 字），極度契合 TTS 逐句合成與 1080p 字幕 1～2 行排版。
5. **語言與標點嚴格限制（TTS 與字幕最佳化）**：
   - **極小化英文**：專業術語、公司名稱與人名盡量採標準中文通譯（如「美國航太總署」、「超微半導體」、「輝達」），避免中文 TTS 朗讀英文時的機械拼讀或發音破裂。
   - **標點符號極簡化（只允許 `，`、`？`、`！`）**：
     - 禁止使用冒號 `：` 與各類引號 `「」`、`“”`（徹底杜絕引號孤立或斷句碎裂）。
     - 禁止使用省略號 `……` 或分號。
     - 句中停頓統一用 `，`；發問設問用 `？`；感嘆強調用 `！`；句末換行直接斷句。
